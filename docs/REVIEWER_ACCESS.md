# InvestEval 评审访问说明

## 当前状态

- Web 产品：<https://investeval-governance.gao44y.chatgpt.site/> （私有）
- 源代码：<https://github.com/yuanzou0/investeval-governance> （私有）
- 评审账号：待获取评审方指定邮箱后授权

“部署成功”不等于“评审可访问”。未使用评审身份复验前，清单保持未完成。

## 提交前操作

1. 向评审方确认用于访问的邮箱。
2. 在 Web 项目中为该邮箱授予查看权限，不授予部署或编辑权限。
3. 在 GitHub 私有仓库中添加只读协作者。
4. 使用与创建者会话隔离的新浏览器会话，以评审账号打开两个链接。
5. 验证评审者可以：读取 README；查看产物 JSON；打开 Web 五个导航；筛选 `ANSWER_RELEVANCE_FAILURE`；查看改善闭环。
6. 不使用管理员账号会话的截图代替评审身份验收。

## 失效兜底

保留一份不含 `.git`、缓存、密钥或个人信息的小于30MB提交包。包内至少包含 `README.md`、`dist/`、`src/`、`data/`、`artifacts/`、`tests/` 和 `docs/`，以及60–180秒演示视频。

## 安全边界

- 只授予评审所需的最小读取权限。
- 不在页面、文档或视频中记录评审邮箱。
- 不共享API密钥、个人仓库令牌或创建者登录态。
- 评审结束后按招聘流程要求回收临时权限。
