# InvestEval AI 使用与验证记录

## 记录目的

本文记录 InvestEval 开发过程中 AI 的参与范围、产生的工件、验证方法和证据边界。它用于说明哪些内容由 AI 辅助完成、哪些检查由确定性程序执行，以及哪些结论仍需人工或真实数据验证。

记录日期：2026-09-27  
项目阶段：24 小时可运行原型  
AI 工具：Codex 编码助手  
运行时模型标识：项目未单独记录服务端精确模型版本，因此不做具体型号声明

## AI 没有承担的工作

- 没有调用扶摇、iFinD 或其他实时金融数据；
- 没有访问或处理真实用户账户、持仓、交易或身份数据；
- 没有生成真实投资建议或收益预测；
- 没有替代人工合规结论；
- 没有执行真实线上 A/B 实验；
- 没有证明当前规则对开放世界投资问答具有泛化能力。

## 运行时 AI 角色

当前产品运行时不调用 LLM。这样设计是为了让第一版证据可复现，并避免用第二个模型凭印象判断第一个模型的金融数字是否正确。

确定性程序负责 Claim 与 Fact 比较、日期和报告期判断、KYC风险匹配、用户画像授权字段检查、收益承诺模式检测，以及配对指标和上线硬门槛计算。

未来 LLM 可以负责从自然语言回答中识别意图和抽取待核验 Claim、识别答非所问与复杂语义风险、汇总多个数据源冲突，以及为人工审核提供解释和优先级建议。即使接入 LLM，金融数字核验、权限、隐私和上线硬门槛也不应只依赖模型判断。

```bash

```

最近一次本地结果：23 项测试通过，0 项失败。

覆盖范围包括四类意图、11条样例预期错误码、正常案例、画像事实不变性、重复事实ID、Bad Case筛选和详情、人工复核持久化、日志导入原子性、版本配对一致性、HOLD 原因、用户反馈边界，以及热点过期、未来信息泄漏和事件日期错配。

### 基线评测复现

```bash
PYTHONPATH=src python3 -m investeval.cli evaluate \
  --facts data/facts.json \
  --cases data/cases.json \
  --output artifacts/evaluation-results.json
```

- 样本数：11；
- 正常通过：2；
- Bad Case：9；
- 基线回答通过率：18.18%；
- 预期错误标签复现：11/11。

18.18%是故意包含大量异常的压力测试集质量，不是评测器准确率。

### 版本对比与门控复现

```bash
PYTHONPATH=src python3 -m investeval.cli compare \
  --runs data/version-runs.json \
  --output artifacts/version-comparison.json
```

| 指标 | Baseline | Candidate | 变化 |
|---|---:|---:|---:|
| 通过率 | 18.18% | 72.73% | +54.55pp |
| 平均分 | 71.82 | 94.55 | +22.73 |
| 证据覆盖 | 81.82% | 90.91% | +9.09pp |
| P95 延迟 | 610ms | 840ms | +230ms |

门控结论：`HOLD`。通过门槛为通过率改善、证据覆盖和阻断类错误；失败门槛为配对样本量 11 小于 30、P95 延迟 840ms 高于 800ms。因此，质量改善没有被解释为可直接上线证据。

## AI 生成内容的主要风险

| 风险 | 当前控制 | 剩余风险 |
|---|---|---|
| 合成数字被误认为真实行情 | 页面、README和JSON均标注 synthetic/fixture | 观看者仍可能忽略说明 |
| 规则对开放语言覆盖不足 | 保存具体错误码并限制结论范围 | 隐含承诺、反讽和复杂上下文可能漏检 |
| 小样本指标被过度解释 | 样本量设为硬门槛并输出 HOLD | 11条样例不能估计真实泛化表现 |
| AI生成代码存在缺陷 | 23项测试、语法和HTTP检查 | 尚无独立安全审计和生产负载测试 |
| Candidate结果被误认为真实实验 | 标注为合成配对输入 | 尚未运行真实模型或线上流量 |
| 自动评测替代人工合规判断 | 高风险案例进入人工复核 | 部署版还不是多用户审计系统 |

## 结论边界

当前证据支持：原型能够运行确定性治理；错误、证据、版本、复核状态和决策可以追溯；Candidate 在合成配对样例上优于 Baseline；样本量和延迟门槛阻止了不充分的上线结论。

当前证据不支持：评测器在真实投资问答上达到100%准确率；Candidate 达到生产上线标准；产品已经完成实时金融数据或 iFinD 集成；系统可以替代持牌投资顾问、金融分析师或合规人员。
