本文记录 InvestEval 开发过程中 AI 的参与范围、产生的工件、验证方法和证据边界。它用于说明哪些内容由 AI 辅助完成、哪些检查由确定性程序执行，以及哪些结论仍需人工或真实数据验证。

## AI 没有承担的工作

- 没有调用扶摇、iFinD 或其他实时金融数据；
- 没有访问或处理真实用户账户、持仓、交易或身份数据；
- 没有生成真实投资建议或收益预测；
- 没有替代人工合规结论；
- 没有执行真实线上 A/B 实验；
- 没有证明当前规则对开放世界投资问答具有泛化能力。

## 运行时 AI 角色

当前产品运行时不调用 LLM。这样设计是为了让第一版证据可复现，并避免用第二个模型凭印象判断第一个模型的金融数字是否正确。

确定性程序负责 Claim 与 Fact 比较、日期和报告期判断、KYC风险匹配、用户画像授权字段检查、收益承诺模式检测，以及配对指标和上线硬门槛计算。

当前答非所问由结构化的 `required_answer_aspects` 与 `covered_answer_aspects` 计算覆盖率，可重放且便于人工核查。未来 LLM 可以负责从开放自然语言中抽取意图、必需要点和待核验 Claim，识别复杂语义风险、汇总多个数据源冲突，以及为人工审核提供解释和优先级建议。即使接入 LLM，金融数字核验、权限、隐私和上线硬门槛也不应只依赖模型判断。

## 验证记录

### 自动化测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

最近一次本地结果：30 项测试通过，0 项失败。

覆盖范围包括四类意图、32条分层配对样本、按意图结果与回归检查、13条压力样例预期错误码、回答要点覆盖与可执行修复闭环、画像事实不变性、Bad Case筛选和详情、人工复核、版本配对一致性、HOLD 原因、行为观察配对一致性，以及热点时间检查。

行为与热点对比使用相同的16个观察 `pair_id`、案例分配和4个热点 `check_id`。Baseline→Candidate 的合成结果为：负向信号率75%→25%、升级调查案例7→2、热点失败3→0。原始 Baseline 异常仍保留并继续验证检测能力；这些数值不代表真实线上用户反馈或因果效果。

场景分层集包含32条合成案例，四类意图各8条，Baseline 每类预设5条正常和3条异常。该设计用于均衡覆盖而非模拟真实流量，20/32的基线通过数由抽样方案预先决定，不能当作线上模型准确率。

### 基线评测复现

```bash
PYTHONPATH=src python3 -m investeval.cli evaluate \
  --facts data/facts.json \
  --cases data/cases.json \
  --output artifacts/evaluation-results.json
```

- 样本数：13；
- 正常通过：3；
- Bad Case：10；
- Bad Case压力集通过率：23.08%；
- 预期错误标签复现：13/13。

23.08%是故意包含大量异常的压力测试集质量，不是评测器准确率。

### 版本对比与门控复现

```bash
PYTHONPATH=src python3 -m investeval.cli compare \
  --runs data/version-runs.json \
  --output artifacts/version-comparison.json
```

| 指标 | Baseline | Candidate | 变化 |
|---|---:|---:|---:|
| 通过率 | 62.50% | 90.62% | +28.12pp |
| 平均分 | 91.25 | 98.12 | +6.87 |
| 证据覆盖 | 90.62% | 100.00% | +9.38pp |
| P95 延迟 | 610ms | 840ms | +230ms |

按意图结果为：行情 62.5%→87.5%、财务 62.5%→100%、公告 62.5%→75%、个性化 62.5%→100%。四类均未退化，案例级回归数均为0。

门控结论：`HOLD`。配对样本量、总体通过率改善、意图级回归、证据覆盖和阻断类错误门槛均通过；唯一失败门槛为 P95 延迟 840ms 高于 800ms。因此，质量改善没有被解释为可直接上线证据。

## AI 生成内容的主要风险

| 风险 | 当前控制 | 剩余风险 |
|---|---|---|
| 合成数字被误认为真实行情 | 页面、README和JSON均标注 synthetic/fixture | 观看者仍可能忽略说明 |
| 规则对开放语言覆盖不足 | 保存具体错误码并限制结论范围 | 隐含承诺、反讽和复杂上下文可能漏检 |
| 小样本指标被过度解释 | 样本量与意图退化均设为硬门槛 | 32条合成样例不能估计真实泛化表现 |
| AI生成代码存在缺陷 | 30项测试、语法和HTTP检查 | 尚无独立安全审计和生产负载测试 |
| Candidate结果被误认为真实实验 | 标注为合成配对输入 | 尚未运行真实模型或线上流量 |
| 自动评测替代人工合规判断 | 高风险案例进入人工复核 | 部署版还不是多用户审计系统 |

## 结论边界

当前证据支持：原型能够运行确定性治理；错误、证据、版本、复核状态和决策可以追溯；Candidate 在总体及四类意图的合成配对样例上优于 Baseline；延迟门槛阻止了不充分的上线结论。

当前证据不支持：评测器在真实投资问答上达到100%准确率；Candidate 达到生产上线标准；产品已经完成实时金融数据或 iFinD 集成；系统可以替代持牌投资顾问、金融分析师或合规人员。
